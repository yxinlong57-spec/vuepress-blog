# Spring 实战

Spring 核心原理与整合案例。目标：不止「会用注解」，更懂「注解背后发生了什么」。

## 📌 内容规划

- **核心原理**：IoC 容器、Bean 生命周期、AOP、事务
- **Spring Boot**：自动装配、Starter 机制、内嵌容器
- **整合案例**：MyBatis、Redis、消息队列、定时任务
- **进阶**：自定义 Starter、扩展点（BeanPostProcessor 等）

## 🧭 使用建议

结合源码调试阅读：把案例代码跑起来，打断点跟着 Bean 走一遍生命周期，比看十篇文章都管用。
