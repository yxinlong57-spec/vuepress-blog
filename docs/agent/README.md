# Agent 探索

我的第二条主线：**Java 后端打底，Agent 应用探路**。这里记录 LLM 应用开发的学习与实践——从 Agent 基本概念，到 MCP / A2A 协议，再到 Spring AI 集成与 RAG 链路。

## 📌 已收录

- **入门与视野**：AI Agent 新手该先学什么
- **协议与框架**：MCP 接入与安全边界、**用 Java 手写 MCP Server**、A2A 与 MCP 的分工、Agent Skills 工程实践、多 Agent 架构选型、Spring AI vs LangChain4j
- **核心机制**：手写最小 Agent 循环、Function Calling 参数校验、记忆工程、评测方法论
- **上下文与编排**：上下文工程（预算/压缩/分层）、工作流编排（状态图 + 检查点 + 人工介入）
- **Spring AI 与 RAG**：工具调用执行链、Java 手写最小 RAG、Agentic RAG（改写 + 混合召回 + 重排 + 纠错循环）
- **生产化与治理**：Agent 可观测性（Span 树、指标、成本账本）

## 🧭 写作原则

所有实验都写明 JDK、框架版本和可复现代码；说清「实验支持什么、不能证明什么」，不把概念搬运当实践。
