# 面经手册

面试八股 + 底层原理，按主题系统梳理。不做单纯的八股文堆砌：每个知识点都从「是什么」讲到「为什么」，再落到「怎么答」。

## 📌 内容规划

- **集合源码**：HashMap、ConcurrentHashMap、ArrayList…
- **并发编程**：线程池、锁、AQS、volatile…
- **JVM**：内存模型、垃圾回收、类加载…
- **MySQL**：索引、事务、锁、日志…
- **Redis**：数据结构、持久化、缓存问题…
- **计算机网络**：TCP/UDP、HTTP/HTTPS…

## 🧭 使用建议

求职季按章节系统过一遍；平时看完技术文后回来对照「面试怎么答」小节巩固。
