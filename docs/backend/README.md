# 后端进阶

Redis、消息队列与分布式。后端工程师从「CRUD」走向「架构」的必修课。

## 📌 内容规划

- **Redis**：数据结构与应用、持久化、缓存三兄弟（穿透/击穿/雪崩）、分布式锁
- **消息队列**：RocketMQ/Kafka 基础、可靠投递、幂等消费
- **分布式**：CAP、分布式事务、分布式 ID、限流熔断
- **微服务**：注册中心、网关、链路追踪

## 🧭 使用建议

每个中间件先问三个问题：解决什么问题？有没有替代方案？用了会引入什么新问题？
