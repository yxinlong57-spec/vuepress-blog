# Java 基础

地基打得越牢，楼才盖得越高。这里记录 Java 语言本身的那些「为什么」：从 `==` 和 `equals` 的区别，到 Scanner 的光标行为，再到 BIO / NIO / AIO 的模型差异。

## 📌 已收录

- **语法与判等**：== 与 equals 的判断路径、Scanner nextLine 跳行
- **集合选型**：ArrayList vs LinkedList，别只看「插入删除快慢」
- **网络编程**：BIO / NIO / AIO 三种 IO 模型，从阻塞方式到代码模型

## 🧭 使用建议

每篇都从真实踩坑切入，代码可直接复制运行。看完别背结论，把复现代码自己跑一遍。
