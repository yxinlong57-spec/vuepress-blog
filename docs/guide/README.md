# 阅读指南

欢迎来到 Loong 的技术栈。本站按「专栏」组织内容，每个专栏独立成体系，按章节顺序阅读效果最佳。

## 🗺️ 专栏地图

### 1. [面经手册](/interview/)

面试八股 + 底层原理，按主题系统梳理。适合求职季系统复习，也适合日常查漏补缺。

- 推荐起点：[HashMap 源码解析](/interview/hashmap-source.html)

### 2. [Spring 实战](/spring/)

Spring 核心原理与整合案例，从 IoC、AOP 到自动装配，逐步深入。

- 推荐起点：[Spring Boot 自动装配原理](/spring/auto-configuration.html)

### 3. [后端进阶](/backend/)

Redis、消息队列与分布式，后端工程师的进阶必修课。

- 推荐起点：[Redis 常用数据结构与应用场景](/backend/redis-data-structures.html)

### 4. [项目实战](/projects/)

从 0 到 1 的项目复盘：需求、设计、踩坑、优化，完整还原。

- 推荐起点：[从 0 搭建 VuePress 博客并自动化部署](/projects/vuepress-blog.html)

### 5. [技术随笔](/daily/)

不定期更新：踩坑记录、效率工具、学习心得。

## 📌 建议的学习路线

```text
Java 基础 → 集合/并发源码（面经手册）
         → Spring 原理（Spring 实战）
         → Redis / MQ / 分布式（后端进阶）
         → 动手做项目（项目实战）
```
