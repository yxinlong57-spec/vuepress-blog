简历是面试的入场券，也是面试的考题来源——面试官的追问基本都从你的简历出发。这里把专栏的简历系列文章和实用模板收拢到一处。

系列文章：项目经历怎么写

按「先总后分」的顺序读：

  1. Java 后端简历怎么写？附一份可直接参考的完整草稿 —— 先看这篇，建立整体框架：专业技能、项目经历、教育背景每一块怎么落笔。
  2. 黑马点评简历怎么写？别只堆缓存三兄弟，给出一份能追问的 Redis 项目模板 —— Redis 项目包装：缓存、秒杀、分布式锁怎么写出深度。
  3. 黑马商城简历怎么写？把订单、库存和支付链路写成硬实力 —— 交易链路包装：订单、库存、支付的一致性怎么讲。
  4. 黑马头条能写进简历吗？能，但别把它写成大厂项目 —— 学习项目的正确定位：诚实但不掉价。

简历结构模板

可直接套用的骨架（每块的写法细节看上面第 1 篇）：

# 姓名 —— Java 后端开发（求职意向）

📱 电话 | 📧 邮箱 | GitHub / 博客链接

## 专业技能
- 熟悉 Java 集合、并发、JVM，读过 HashMap / AQS 核心源码
- 熟悉 Spring / Spring Boot，了解自动装配原理
- 熟悉 MySQL 索引、事务、慢查询优化；熟悉 Redis 缓存与典型问题治理
- （写你真正能讲 10 分钟的，不写「精通」）

## 项目经历
### 项目名（一句话定位）          20xx.xx - 20xx.xx
- 背景与规模：解决什么问题，什么量级
- 我的职责：负责哪几个模块
- 技术亮点 1：问题 → 方案 → 量化结果（如 QPS / 耗时下降比例）
- 技术亮点 2：同上，2~3 个亮点足够

## 教育背景
学校 · 专业 · 学历（20xx - 20xx），相关课程 / 成绩亮点（可选）

三条铁律：

  • 写上去就要能被追问：每个技术点都准备「为什么用、怎么实现、还有什么方案」三层回答
  • 亮点要有量化：没有数字的优化等于没做（哪怕是自己压测的数字）
  • 一页纸：校招简历一页足够，删减永远比堆砌难
