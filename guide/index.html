阅读指南

欢迎来到 Loong 的技术栈。本站按「专栏」组织内容，每个专栏独立成体系，文章均带可复现的实验代码。

🗺️ 专栏地图

1. Java 基础

语言层的每个「为什么」：== 与 equals、Scanner 输入行为、集合选型、BIO / NIO / AIO。

  • 推荐起点：== 和 equals 到底有什么区别

2. 面经手册

面试八股 + 底层原理，按主题系统梳理，附「简历与求职」章节。适合求职季系统复习，也适合日常查漏补缺。

  • 推荐起点：HashMap 的核心结构

3. Spring 实战

Spring 核心原理与整合案例，不止「会用注解」，更懂「注解背后发生了什么」。

  • 推荐起点：Spring Boot 4.1 的 API 版本控制

4. 后端进阶

MySQL、Redis、存储与 IO，后端高频问题逐一本地实测。

  • 推荐起点：缓存穿透、击穿、雪崩到底差在哪

5. Agent 探索

第二条主线：MCP / A2A 协议、Agent 循环与记忆、Spring AI 集成、RAG 链路，Java 视角的大模型应用开发。

  • 推荐起点：AI Agent 入门：新手先学什么

6. 项目实战

从 0 到 1 的项目复盘：需求、设计、踩坑、优化，完整还原。

  • 推荐起点：从 0 搭建 VuePress 博客并自动化部署

📌 建议的学习路线

Java 基础（语言层）
  → 集合 / 并发 / JVM（面经手册）
  → Spring 原理（Spring 实战）
  → MySQL / Redis / 存储（后端进阶）
  → 动手做项目（项目实战）
  → Agent / LLM 应用（Agent 探索）
